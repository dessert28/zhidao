# 智诊通答辩 · 视觉规范

## 定位

7 分钟答辩（上限 8 分钟），15 页。受众是竞赛评委（技术 + 产品双背景）。
一页一个论点，正文硬上限 45 字，全片汉字 ≤ 900 —— 幻灯片是证据，不是讲稿。

## 网格

- 画布 1280 × 720，安全区：左右 84、上 68、下 56（内容宽 1112，可用高 596）
- 分区：标题带 68–118 / 主张带 126–166 / 内容 190–640 / 图注 648–672 / 页脚 686–706
- 断栏只用 3:9、4:8、6:6、12，永不用居中 1:1 分割（封面、P15 除外）

## 蒙德里安规则

1. 线只两档：1px 结构细线（`#14110F` 或深青）、3px 主分割线（仅封面、P3、P15）
2. 每页色块 1–3 个，单个 ≤15% 画面，必须贴边出血，不悬空
3. 分割点落在 1/3 或 2/3 处，非对称
4. 每页网格线 ≤4 条，端点必须落在栏线或色块边上
5. 每页只有一个视觉焦点，其余元素压低对比

## 页脚三段指示器

`去之前 — 在院内 — 回家后`，13px。P1–P3 不显示；P4–P7 高亮「去之前」；P8 高亮「在院内」；P9–P12 高亮「回家后」；P13–P15 隐藏。

## 截图装裱

1px `rgba(20,17,15,0.16)` 描边 + 6px 卡白衬底；禁投影、倾斜、圆角、渐变蒙版。
