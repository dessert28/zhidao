## 一句话定位

**把一次就诊拆成「去之前—在院内—回家后」三段，做成一生连续的跨院管理——而不是又一个挂号 App。**

患者自愿上传病历，数据留在浏览器本地，系统只做整理、提醒、编排，不做诊断。
