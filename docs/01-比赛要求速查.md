### 3.4 在线演示（可选加分）

公网可访问地址、评审期保持可用、需登录则提供测试账号。

> **本项目的决定：不提供线上地址，改用录屏 + 本地一键启动。**
>
> 原因写在这里，免得答辩被问到时答不上：在线演示要求"评审期间保持可用"，
> 而免费托管档普遍有硬约束 —— 要么要求绑信用卡做身份验证（Render），
> 要么单个服务的 512 MB 内存上限装不下 JVM + Node（Northflank 免费项目），
> 要么把 Docker 托管改成收费（Hugging Face Spaces，2026-11-18 实测）。
> 靠本机临时隧道顶一个月不可行：电脑一关地址就死，评审点开是 502。
>
> 如确需线上演示，按 `docs/14` §1~§7 在任意一台 ≥1 GB 内存的服务器上部署即可，
> 本次不为省赛临时开付费机器。

### 3.5 注意事项

- API 密钥不得出现在公开仓库，必须走环境变量
- 提交后不得修改
- 材料不完整影响评审

## 5. 技术栈建议（赛道官方推荐）

### 前端框架
React + Next.js 14+（首选）、Vue 3 + Nuxt 3、Svelte 5 + SvelteKit、React + Vite、Astro

### UI 与样式
Tailwind CSS（强烈推荐）、shadcn/ui、Ant Design / Element Plus、Framer Motion / GSAP、Three.js / R3F

### 前端 AI 集成
**Vercel AI SDK（推荐首选）**、LangChain.js、Transformers.js、WebGPU / ONNX Runtime Web、Web Speech API、MediaPipe

### 模型接入
LLM：OpenAI、Anthropic Claude、Google Gemini、智谱 AI、DeepSeek
多模态：GPT-4o、Gemini Pro Vision、通义千问 VL
图像：DALL·E 3、Stability AI
语音：Whisper、TTS

### 状态与数据
Zustand / Jotai / Pinia、TanStack Query、IndexedDB / LocalStorage、WebSocket / SSE

### 工具
Cursor / Copilot / Windsurf、Figma / v0.dev、Storybook、Git、pnpm、ESLint + Prettier + TypeScript

## 6. 特别说明（原文要点）

- 作品须**以前端 Web 应用为主要呈现形态**，后端仅作 AI 能力接入层，不作重点考察
- 鼓励用 Next.js API Routes / Nuxt Server Routes 简化后端
- 允许 AI 辅助编程，但选手须能解释所有代码逻辑
- 商业 API 费用自担，鼓励用免费额度
- 鼓励探索浏览器端 AI 推理（Transformers.js、WebGPU），体现端侧智能前瞻性
- 涉及用户数据的应用须遵守法律法规，做好隐私保护
