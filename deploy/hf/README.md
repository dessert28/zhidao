# 智诊通 · 患者端智能导诊系统

> 把一次就诊拆成「去之前 — 在院内 — 回家后」三段，做成跨院的连续管理——而不是又一个挂号 App。

这是 **2026 全国高校 AI Web 开发挑战赛（传智杯）** 参赛项目的在线演示实例。

- 完整源码与设计文档：<https://github.com/dessert28/zhidao>
- 技术栈：React 18 + Vite 6 + TypeScript + Node BFF（Hono）+ Spring Boot 3 + H2

## 可以先看什么

| 入口 | 试试什么 |
| --- | --- |
| 首页「今日」 | 今天几点吃什么药、有哪些待办 |
| 问诊 | 输入「肚子疼三天了，是胀痛」，看分诊与科室推荐 |
| 红线测试 | 输入「我爸突然胸口疼得还出冷汗」，看它在调用模型之前就短路 |
| 健康管家 | 上传一份化验单照片，看指标解释与复查提醒 |
| 病历 | 跨院时间轴、重复检查提示（演示账号 `demo` / `demo1234`） |

## 两点说明

- **冷启动**：免费实例在长时间无访问后会休眠，首次打开需要等 30~60 秒，
  之后速度正常。这不是应用本身的问题。
- **未配置大模型密钥**：本实例走**规则路由**，功能链路完整可演示，
  但回答不经模型生成。配置 `LLM_API_KEY` 后同一套代码会自动切到模型模式
  （`/api/health` 会显示当前模式）。
